## 🛠️ Key Topics & Technical Highlights
- **Symmetric Ciphers:** Complete breakdown of DES, 3DES, AES (128/192/256-bit key variants), and Feistel Architecture.
- **Asymmetric Ciphers:** Public-Private key generation, RSA encryption/decryption formulas, discrete logarithm problems, and ECC key size comparisons.
- **Cipher Modes of Operation:** Electronic Codebook (ECB), Cipher Block Chaining (CBC), Cipher Feedback (CFB), Output Feedback (OFB), and Counter (CTR).
- **Security Protocols & Verification:** SSL/TLS, IPSec, Hash Functions (SHA family), Digital Signatures, and OAEP Padding mechanisms.
